# Звонки с компьютера из Vertux Workspace

Проверено 8 октября 2026. «Набрать» передаёт телефон клиента программе,
назначенной в Windows для ссылок TEL. Для разговора нужны оператор связи,
подключённая линия и гарнитура. Пароли телефонии в Workspace не вводятся.

## Какой вариант выбрать

| Вариант | Где идёт разговор | Что потребуется |
|---|---|---|
| Номер с SIP + MicroSIP | Через интернет и гарнитуру ПК | Номер и линия у оператора, MicroSIP, назначение TEL |
| Т-Мобайл + «Связь с телефоном» | Через мобильную SIM, звук на ПК | Телефон рядом, Bluetooth, сопряжение |
| Телефония внутри Workspace | В окне продукта | Отдельная интеграция АТС и работа с аудио в Nexus |

Для рабочего места менеджера без привязки к личному телефону подходит первый
вариант. Для России ниже разобран **Novofon + MicroSIP**. Это подготовленный путь,
а не уже оформленная линия или подтверждённый звонок.

## Вариант 1. Novofon + MicroSIP

Схема: **«Набрать» в Workspace → MicroSIP → оператор → телефон клиента**.
Звук идёт через микрофон и наушники ПК; номер клиента перепечатывать не нужно.

1. **Оформить номер.** В Novofon открыть «Администратор → Управление номерами».
   До оплаты проверить аренду, исходящие направления и требования оформления.
   Покупка и пополнение при проверке Workspace не выполнялись.
2. **Выделить менеджеру линию.** Добавить сотрудника и настроить входящие и
   исходящие. Выбрать подключённый номер для показа получателю; произвольный
   номер в поле имени MicroSIP этого не обеспечивает.
3. **Установить MicroSIP** с [официального сайта](https://www.microsip.org/downloads).
   Использовать обычную установку с регистрацией телефонных ссылок, если такой
   пункт предложен. В программе открыть «Добавить аккаунт».
4. **Подключить линию.** В Novofon открыть «Настройки → Виртуальная АТС →
   SIP-номера → шестерёнка сотрудника → Учётные данные». Сервер и домен —
   `sip.novofon.ru`; пользователя, логин и пароль взять из этого раздела.
   Вводить их самостоятельно в MicroSIP, не в чат и не в Workspace.
   Дождаться успешной регистрации линии.
5. **Связать кнопку с приложением.** Windows → «Параметры → Приложения →
   Приложения по умолчанию» → найти тип ссылки `TEL` → выбрать **MicroSIP**.
   Если его нет в списке, проверить установку с регистрацией протоколов.
6. **Настроить звук.** В MicroSIP выбрать используемые микрофон и наушники.
7. **Проверить на своём втором телефоне.** Нажать «Набрать», при необходимости
   подтвердить открытие приложения. Проверить слышимость в обе стороны,
   отображаемый исходящий номер и обратный вызов. Затем завершить разговор.
   До этой проверки линия не считается готовой.

Источники: [кабинет и номера Novofon](https://novofon.com/instructions/novofon/onboarding-novofon/),
[настройка MicroSIP у Novofon](https://novofon.com/instructions/calls/microsip-windows/),
[поддержка TEL в MicroSIP](https://www.microsip.org/faq).

Прежний пример с Zadarma для российского сценария заменён: оператор
[сообщает, что не предоставляет услуги в России](https://zadarma.ru/).
Его серверы `sip.zadarma.com` и `pbx.zadarma.com` к Novofon не относятся.

## Вариант 2. Виртуальный номер Т-Мобайла

Это дополнительный номер на существующей SIM с общим тарифом и счётом.
Покупка услуги сама по себе не создаёт подключение к MicroSIP.
В Т-Мобайле можно включить исходящие с виртуального номера; пока переключатель
активен, обычные вызовы и СМС идут с него.
[Описание и управление услугой](https://www.tbank.ru/mobile-operator/help/communication/sim-card/more-services/types/).

1. Связать смартфон с приложением Windows «Связь с телефоном».
2. Включить Bluetooth на обоих устройствах, завершить сопряжение и разрешить
   работу со звонками на телефоне. Телефон должен оставаться рядом.
3. В Т-Мобайле включить исходящие с виртуального номера.
4. Проверить на своём втором номере звук и показ номера. Если Windows предлагает
   «Связь с телефоном» для TEL, назначить его и отдельно проверить кнопку
   Workspace. Иначе скопировать номер из карточки и набрать в приложении.

[Microsoft описывает звонки с ПК через Bluetooth для Android и iPhone](https://support.microsoft.com/ru-ru/windows/apps/make-and-receive-phone-calls-from-your-pc).
Совместная работа Т-Мобайла, конкретного смартфона и кнопки Workspace здесь
ещё не проверена. Этот вариант зависит от телефона.

## Что подготовлено и что осталось

- Установленный Nexus 0.6.46 блокирует чужие переходы внутри окна. Для TEL у него
  предусмотрен маршрут нового окна; кнопка и телефонная ссылка теперь используют
  этот маршрут.
- В карточке компании и разделе «Звонки» есть инструкция подключения.
- На проверенном ПК не найдены MicroSIP/Zoiper, «Связь с телефоном» и назначенный
  обработчик TEL. Учётная запись оператора не настраивалась.
- Нажатие «Набрать» не создаёт запись об успешном разговоре. Менеджер сохраняет
  фактический итог после звонка; подтверждение соединения от оператора не приходит.

Если программа не открылась, проверь назначение TEL или скопируй номер.
Если открылась, но линия не зарегистрирована, проверь настройки у оператора.
Если вызов идёт без звука — выбранные устройства, разрешение на микрофон и сеть.

Для автоматической длительности, записей и статусов нужна интеграция с API
выбранной АТС. Звонок полностью внутри Workspace тоже требует отдельной работы:
текущая продуктовая сессия Nexus запрещает микрофон. Это не мешает отдельному
MicroSIP использовать свои разрешения.

Для бизнеса условия маркировки исходящих и использования линии уточняются
у выбранного оператора. Готовность подтверждается согласованным тестовым звонком.

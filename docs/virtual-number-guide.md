# Виртуальный номер для менеджера Vertux

Сейчас «Набрать» открывает tel:+7…. Телефония, исходящий номер, минуты и запись
разговора принадлежат оператору и приложению для звонков. Логин или пароль SIP
вводить в Workspace не нужно.

Схема: **Workspace → приложение менеджера → оператор → клиент**.
Для первого менеджера достаточно приложения оператора или совместимого
SIP-клиента. Встраивать АТС в Workspace для этого необязательно.

## После покупки номера

1. У оператора проверить исходящие по нужным направлениям, возможность показывать
   купленный номер как Caller ID, обратные входящие и условия оформления.
   Номер только для SMS или только входящих эту задачу не решает.
2. В кабинете оператора создать отдельный внутренний аккаунт менеджера,
   подключить входящие и выбрать подтверждённый исходящий номер. Задать лимит расходов.
3. На компьютере менеджера открыть приложение оператора или поддерживаемый
   SIP-клиент. Ввести выданные сервер, логин и пароль **в этом приложении**.
   Пароль основного кабинета владельца менеджеру не требуется.
4. Проверить подключение, микрофон и наушники. Сделать согласованный тест на свой
   второй телефон: звук в обе стороны, показ номера, затем обратный звонок.
5. Если клиент регистрирует обработчик TEL, выбрать его в Windows:
   «Параметры → Приложения → Приложения по умолчанию → выбор по типу ссылки».
   При нажатии «Набрать» Windows может предложить приложение. Поведение зависит
   от клиента; реальный набор в этой работе не проверялся.
6. Если TEL не поддерживается, нажать «Скопировать номер», вставить в приложение,
   провести разговор и выбрать в Workspace «Записать ручной звонок» → фактический
   итог. Сохранить договорённость и дату следующего контакта.

Пример настройки, а не выбранный поставщик:
[инструкция Zadarma для MicroSIP](https://zadarma.com/ru/support/instructions/windows/microsip/).
Для обычного SIP-аккаунта указан sip.zadarma.com, для внутреннего аккаунта АТС —
pbx.zadarma.com. К другому оператору эти значения неприменимы. Аренда номера,
минуты, переадресация и запись могут оплачиваться отдельно; тариф здесь не выбран.

Для звонков от организации/ИП согласовать с оператором маркировку исходящих:
[инструкция МТС для бизнеса](https://support.mts.ru/mobilnaya-svyaz-b2b/obyazatelnaya-markirovka-zvonkov/markirovka-zvonkov-dlya-biznesa).
Публичный номер не подтверждает согласие на рекламные звонки:
[статья 18 закона о рекламе](https://base.garant.ru/12145525/a573badcfa856325a7f6c5597efaaedf/).

## Для автоматического журнала

Нужна отдельная интеграция с API выбранной АТС: серверный запуск вызова,
проверка подписи уведомлений, ID и статусы звонка, привязка сотрудника,
защита повторных уведомлений, правила хранения и доступа к записи.
[API Zadarma](https://zadarma.com/ru/support/api/) — один из примеров, провайдер пока не выбран.

Live-суфлёр распознаёт выбранный микрофон, если браузер поддерживает распознавание.
В гарнитуре голос клиента обычно не попадает в этот микрофон. Для разбора обеих
сторон нужен разрешённый транскрипт/запись АТС и отдельный путь обработки.
Наличие кнопки микрофона не доказывает такую интеграцию.

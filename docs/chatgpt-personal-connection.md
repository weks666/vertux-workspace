# Личная подписка ChatGPT в Workspace

Этот режим предназначен для личного Workspace владельца студии. Используется официальный Sign in with ChatGPT (SIWC), доступность которого зависит от аккаунта и разрешения OpenAI. Рабочий сервер не читает сессии Codex, историю ChatGPT или сохранённые пароли браузера. Подписка не превращается в долларовый API-бюджет; лимиты приложения и подписки учитываются отдельно.

**Текущее состояние, 11 октября 2026:** личный AI-модуль размещён на существующем AI-сервере `31.44.4.244`, рядом с отдельными службами тренера и Invest. Сбор сайтов, очередь и CRM остаются на прежнем data plane. Из нового контейнера OpenAI discovery/JWKS отвечают HTTP 200, token endpoint на неполный запрос без кода — HTTP 400 `invalid_request`. Региональная ошибка прежнего сервера не воспроизводится в этой проверке. Личный вход, доступ подписки и реальный ответ модели пока не подтверждены; AI выключен. После успешного подключения компьютер не нужен для ежедневной работы.

Причина прежнего отказа: основной сервер получал HTTP 403 `unsupported_country_region_territory`. Его OAuth-listener теперь выключен; основной сервер больше не обменивает код и не обновляет ChatGPT-токены. Старые токены не переносились (подтверждённого входа не было). Для нового AI-хоста создаётся отдельный постоянный host ID и выполняется новый личный вход.

## Первый вход

1. Если прежний помощник ещё открыт, нажми Enter в его окне, чтобы закрыть старое соединение. Затем запусти двойным щелчком `scripts/connect-workspace-chatgpt.cmd` из проверенного checkout. Он открывает защищённое соединение с новым AI-хостом и страницу входа. Занятый локальный порт вызывает понятное сообщение; чужие процессы не останавливаются. Не передавай ключи, пароль или коды в чат.
2. Нажми «Продолжить с ChatGPT» и выполни вход на странице OpenAI. Подтверди только разрешения, которые хочешь предоставить этому личному Workspace.
3. После сообщения «ChatGPT подключён» вернись в Workspace → Исследования → Настройки → «Проверить подключение».
4. Выбери модель из полученного списка и дневной лимит запросов. AI включается отдельным действием. Автоматический Deep, если включён, относится к доступным компаниям всего этого Workspace.

До входа обычный Quick Scan, ограниченное исследование сайтов, источники, скоринг и шаблоны материалов работают без LLM. На OpenRouter автоматически не переключаются. Если OpenAI не разрешает этот способ для аккаунта, исследования можно заказывать в обычном чате; это отдельный ручной процесс, результаты которого не импортируются автоматически.

Двойной щелчок по `.ps1` может открыть редактор, поэтому добавлен `.cmd`. Для текущего личного checkout можно также нажать Win+R и выполнить:

```powershell
"C:\Users\figri\Downloads\MyPlugins\sitecreate\.worktrees\vertux-lead-intelligence-20261010\scripts\connect-workspace-chatgpt.cmd"
```

Окно PowerShell должно оставаться открытым до завершения входа, затем нажми Enter. Параметр запуска не меняет постоянную политику Windows и не требует прав администратора. Начинай заново с `http://127.0.0.1:47922/`, а не обновляй страницу `/auth/start` с прежней отправленной формой. Помощник не добавляет автозагрузку и не меняет VPN.

Регрессия формы проверяется отдельно: `node tests/verify-chatgpt-loopback.cjs`. Тест использует изолированный Chromium, подставной провайдер и только loopback; проверяет реальный клик, отсутствие Referer при перенаправлении, привязку callback к браузеру и запрет повторного callback. Обычные HTTP-проверки с вручную заданным Origin эту браузерную ошибку не обнаруживали.

## Лимиты и отключение

Один запрос к модели резервируется до отправки в основной базе и дополнительно на AI-хосте. Постоянный идентификатор запрещает повторное выполнение после сетевого сбоя или перезапуска. Прерванный ответ также занимает дневной слот. Обе стороны ограничены 10 запросами в сутки по Europe/Moscow; лимит приложения не равен лимиту подписки. Суммы в долларах для этого режима не показываются. Фактические токены сохраняются по ответу OpenAI; доступный остаток подписки проверяется в [ChatGPT → Usage](https://chatgpt.com/settings/usage). При исчерпании лимита AI отключается, и это состояние сохраняется после перезапуска. Первый вход не снимает начальную паузу AI-хоста — её снимает только явное включение AI владельцем.

«Отключить ChatGPT» сначала выключает AI в Workspace, затем приостанавливает новые обращения на AI-хосте и прерывает выполняемый запрос до отзыва сессии и удаления токенов. Уже отправленный запрос может занять лимит: прерванный результат остаётся неопределённым, автоматического повтора нет. Если сетевой отзыв не подтверждён, его нужно завершить в настройках ChatGPT. Сохраняются только связка аккаунта/клиента и идентификатор этой VM для повторного входа.

## Операторская схема

Веб-API остаётся на loopback 47921 основного сервера за существующим HTTPS-маршрутом Workspace. `chatgpt-remote.mjs` вызывает только фиксированный HTTPS endpoint личного AI-хоста; перенаправления, автоматические повторы, произвольные upstream-адреса и fallback отсутствуют. На AI-хосте точный nginx route допускает только IP основного сервера; приложение дополнительно проверяет отдельный приватный caller key. Браузер не получает этот ключ. Endpoint принимает только status/models/ready/complete/resume/disconnect; модель выбирается из каталога аккаунта, а анализ ограничен фиксированными инструкциями и проверенными фактами.

OAuth-помощник слушает только `127.0.0.1:47922` AI-хоста; публичного маршрута к нему нет. SSH соединяет этот порт с компьютером владельца только для входа. ChatGPT-токены выдаются, проверяются и обновляются на AI-хосте, сохраняются атомарно в отдельном каталоге с правами 0700/0600. Supabase service role остаётся на основном сервере. Ключи и токены не попадают в CRM или публичную сборку.

Контейнер `vertux-lead-chatgpt` использует уже установленный образ Node 24 по digest, пользователя 1000, readonly root, снятые capabilities, ограничение 128 MiB / 0.35 CPU / 64 PID и автоперезапуск. После запуска занято около 21 MiB; это проверка простоя, не нагрузочная оценка. Постоянный ledger хранит только идентификаторы, дни и состояние запросов. При недоступности AI-хоста CRM и исследование без модели остаются доступны. Helper выпуска: `scripts/lead-chatgpt-host-release.py`, по умолчанию только подготовка и изолированные тесты; `--apply` создаёт службу с backup и откатом nginx.

Обычные изменения CRM и выключение AI не ожидают статуса ChatGPT или списка моделей. На экранах чтения ожидание статуса ограничено 1,5 секунды, каталога — 4,5 секунды; при задержке данные CRM возвращаются с отдельной ошибкой AI. Включение AI требует подтверждённых подключения и каталога; сбой управляющего запроса не сохраняет включение.

Изолированная проверка двух хостов включает повтор запроса, квоты после рестарта, паузу, недопустимые инструкции, отсутствие прав, зависшие транспорт/тело ответа и отключение во время каталога или потока ответа модели. Реальная серверная проверка подтверждает защищённый HTTPS-вызов статуса с основного контейнера, но не вызов модели. Суточный поиск 100 новых компаний — отдельная функция: существующий pipeline исследует импортированную базу; сезонная таблица сама по себе автопоиск не включает.

Вход не является общей регистрацией других клиентов в коммерческом сервисе. Условия SIWC для коммерческих/удалённых предложений рассматриваются отдельно; лицензия репозитория этим изменением не назначается.

# Workspace Lead Intelligence: выпуск 11 октября 2026

Личный Workspace поиска клиентов расширен исследованием компаний, источниками, объяснимым скорингом, материалами для продаж и серверной очередью. Существующие CRM, импорт, финансы и AI-тренер сохранены. Nexus и его установщик этим выпуском не заменяются.

## Рабочий режим

Quick Scan не использует LLM. Фоновая очередь работает на сервере; начальные квоты — 500 Quick и 50 Deep в сутки, расписание — 09:00 Europe/Moscow. На текущем сервере одновременно обрабатывается одна компания. Deep без включённого AI собирает дополнительные данные и формирует явно помеченные шаблонные материалы.

Источник AI для личного Workspace — подписка ChatGPT через официальный SIWC. Аккаунт пока не подключён, AI выключен; предел приложения — 10 обращений в сутки, дополнительно действуют лимиты подписки. Модель выбирается только из каталога подключённого аккаунта. Автоматического перехода на платный API нет: ключ OpenRouter в новой службе отсутствует, денежные бюджеты равны нулю. Это не меняет отдельно существующий тренер.

[Помощник первого входа](chatgpt-personal-connection.md) требует личного входа владельца на странице OpenAI. Доступность SIWC для аккаунта и реальный ответ модели пока не подтверждены. Можно по-прежнему заказывать исследования в обычном чате; автоматического импорта его результатов нет.

## Публикация интерфейса

`scripts/publish-workspace-assets.py` формирует отдельный Git tree из 15 публичных файлов и `.nojekyll`, публикует его в `gh-pages` и проверяет точный Pages commit и SHA-256 каждого файла по HTTPS. Receipt связывает frontend с зафиксированным source HEAD. Серверные исходники, тестовые данные, SQL и конфигурация ключей не входят в статическую раздачу. Результат публикации фиксируется этим helper в приватном release-evidence; этот документ сам по себе не заменяет его проверку.

## Оставшиеся границы

Личный вход ChatGPT остаётся отдельным шагом. Обычный запуск опубликованного продукта в действующей сессии владельца подтверждён. Новые учётные записи не создавались, права владельца не выдавались, сессия владельца не подделывалась. Автоматический запуск помощника SSH для SIWC был отклонён проверкой разрешений среды (`blocked by policy`); сохранён ручной launcher.

Внешний поисковый API, отправка писем и синхронизация inbox не подключены. Поиск сайта использует импортированный URL, контакты и публичные ссылки. Недостаток данных остаётся видимым ограничением. PageSpeed выключен. Реальные лимиты/ответы SIWC и приёмка другим пользователем пока не заявляются.

## Откат

Предыдущие source/frontend commit сохраняются в истории Git; исходный Caddyfile и версия службы — в серверном backup. Edge-helper с `--rollback` и тем же prepared receipt снимает только собственный systemd drop-in и возвращает исходный supervisor. Следующий выпуск KovroCity должен снять или перебазировать overlay: он привязан к проверенному runtime 0.1.11, смена authority закрывает маршрут. При откате интерфейса следует заново проверить HTTPS-файлы и service worker. Перед удалением новых таблиц сохранить появившиеся исследования и журнал расходов; финансовые таблицы и компании rollback модуля не удаляет. Миграцию повторно не применять: применённый receipt сверяется по её точному SHA-256.

# Workspace — выпуск 8 октября 2026

Исправлены план контактов, переключатель Workspace, загрузка системных разделов
Nexus 1.2.3, ввод денег, разделение заявки на демо и его фактической отправки,
CSV/XLSX-слияние и конкурентное сохранение журнала/напоминаний.

Тренер поддерживает ручной транскрипт, короткие подсказки, разбор звонка, ролевую
тренировку и итоговый разбор. Сервер принимает только активных участников нужного
Workspace. Фиксированная модель — OpenAI GPT-4.1 mini через OpenRouter; стоимость
учитывается по ответам провайдера, предварительно резервируется верхняя оценка.
Общий бюджет $5 не сбрасывается в полночь или после рестарта. Неопределённый ответ
оставляет резерв, повторный requestId отклоняется. Health не выполняет генерацию.

Финансы вынесены из `projects.raw` в `workspace_project_finance`. Owner/admin
читают и изменяют деньги; manager ведёт карточки, viewer только читает их.
Проверяются текущие app_metadata, продукт, организация и состояние доступа.
Изменение роли внутри браузера и старая роль из JWT не расширяют эти права.

Добавлены специализированный [промпт Rockefeller](../templates/rockefeller-banquet-prompt.txt),
[CSV-шаблон](../templates/rockefeller-banquet-columns.csv),
[исследование ниши](niche-research-2026-10-08.md) и

## Проверка

Локальный набор покрывает бизнес-правила, конкурентные записи, импорт, ограничения
тренера и запуск через ссылку на версию. UI проверяется на изолированном стенде:
15 сценариев и 10 разделов на ширинах 1440/768/390. У базы отдельные проверки
восстановления, сохранности финансов, чтения/записи разными ролями и отката.
Четыре режима ИИ дополнительно проверяются реальными запросами с вымышленным
диалогом. Внутренние receipts содержат hashes и результат опубликованного smoke.

## Порядок обновления и откат

1. Подготовить приватный backup и выполнить rehearsal через
   `scripts/finance-release.py` без `--apply`. Helper создаёт отдельную БД,
   сверяет восстановление и откат, затем удаляет только эту тестовую БД.
2. Применить миграцию только после успешного rehearsal и проверки неизменности
   источника. Исходный dump остаётся на сервере с приватными правами.
3. Проверить отдельную службу тренера и TLS-маршрут по
   [инструкции сервера](../trainer-server/README.md).
4. Опубликовать статические файлы из проверенного commit. Кеш этой версии — v23.
5. Сверить live SHA-256, запуск из Nexus, системные разделы и реальный ответ ИИ.

Отключение ИИ: вернуть `aiShieldAuthority: false`, выпустить новый кеш и остановить
контейнер тренера. Не удалять его бюджетный файл. Финансовую миграцию оставлять
в силе при обычном откате ИИ. SQL совместимости в `supabase/rollback/` предназначен
только для аварийного отката всей схемы: он возвращает прежние слабые правила,
поэтому требует остановки записи и ограничения доступа команды до исправления.

Кнопка набора по-прежнему передаёт `tel:` внешнему приложению. В текущем Nexus
Desktop продуктовая сессия запрещает микрофон: недоступные кнопки захвата отключены,
а тренер предлагает текстовый ввод. Голосовой режим в браузере и запись обеих
сторон требуют отдельной проверки. Они не подтверждаются тестом текстового ИИ.

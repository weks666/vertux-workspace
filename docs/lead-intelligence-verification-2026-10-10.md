Проверки исправлений включают ограниченное время разбора сложных robots/HTML, общий лимит попыток страниц и сохранение возраста источников при Quick → Deep.

## Для подключения

Полный пример — [`lead-server/.env.example`](../lead-server/.env.example), порядок миграции и запуска — [`lead-server/README.md`](../lead-server/README.md).

Обязательные серверные значения: `LEAD_ENABLED`, `LEAD_SUPABASE_URL`, `LEAD_SUPABASE_ANON_KEY`, `LEAD_SUPABASE_SERVICE_KEY`, `LEAD_ORGANIZATION_ID`, `LEAD_PRODUCT_ID`, приватный `LEAD_USAGE_SALT`, точные `LEAD_ORIGINS`. Для платного Deep: `LEAD_OPENROUTER_KEY`, allowlist модели/провайдера и положительные `LEAD_MAX_KEY_USD`, `LEAD_MAX_DAILY_USD`, `LEAD_MAX_COMPANY_USD`; AI включается отдельно в настройках. Для JS-сайтов нужен `LEAD_BROWSER_IMAGE`; PageSpeed включается отдельно через `LEAD_PSI_ENABLED` и необязательный `LEAD_PAGESPEED_KEY`.

Frontend `CONFIG.leadIntelligenceUrl` сейчас пуст. После разрешённого развёртывания он должен указывать на HTTPS API data plane. До этого экран сообщает, что сервис не подключён; тестовые данные в рабочую страницу не подмешиваются.

## Оставшиеся реальные ограничения

- Изменение не опубликовано и не проверено на production Supabase/установленном клиенте. Перед активацией нужны миграция, служба, HTTPS endpoint и проверка обычного входа владельца/менеджера/наблюдателя.
- Локальный Docker daemon недоступен. Образ и запреты прямого сетевого доступа необходимо проверить на целевом хосте. При отсутствии безопасного renderer JS-контент остаётся неизвестным.
- PostgreSQL-проверки используют PGlite с одной connection. SQL-lock и fencing проверены последовательно; конкуренция нескольких серверных процессов требует отдельной staging-проверки.
- Живые OpenRouter, PageSpeed и внешние сайты компаний не вызывались. Адаптеры и обработка результатов проверены на синтетических ответах; платная генерация не заявляется подтверждённой.
- Email-транспорта/inbox в исходном продукте нет. Доступны черновики и ручной ввод ответа; отправка API не поддерживается, журнал отправленных кампаний не выдумывается.
- Общий поисковый API не подключён: поиск официального сайта использует адреса, корпоративный email и публичные ссылки из карточки/источника. При недостатке доказательств результат остаётся неизвестным.

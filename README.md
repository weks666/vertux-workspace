# Vertux Workspace

Командный центр агентства Vertux: база лидов с воронкой, журнал звонков с аналитикой,
демки, финансы и Vertux Shield — в одном приложении.

Статический SPA без сборки (HTML/CSS/JS). Данные — Supabase, вход по кодам приглашения,
права ролей проверяются на уровне базы (RLS). Ставится как приложение (PWA):
кнопка «Установить» в адресной строке Chrome.

## Локальный запуск

```bash
python -m http.server 8123
# открыть http://localhost:8123
```

Без входа приложение данных не показывает: доступ только для команды по коду приглашения.

Rockefeller используется как исходный сервис обработки: Workspace импортирует его готовый
CSV/XLSX. Файл `n8n/vertux-rockfeller.json` считается экспериментальным архивом и не является
production-заменой Rockefeller. Планируемая автоматизация — локальный Windows browser bridge
с отдельным профилем, ручным первым входом и проверкой файла перед импортом.

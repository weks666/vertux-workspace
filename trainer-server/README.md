# Сервер тренера Workspace

Четыре режима: suffler, review, roleplay, debrief. Node.js 24, встроенный SQLite,
без дополнительных npm-пакетов. Реальные ответы проверены на синтетическом диалоге.

## Рабочий маршрут

Браузер обращается к `https://nexus.vertux.online/api/workspace-trainer`.
Nexus nginx передаёт только необходимые заголовки по проверенному TLS на
`https://zxcqweksn8n.duckdns.org/webhook/vertux-ai-trainer`.
Там точный маршрут ведёт в отдельный контейнер `vertux-workspace-trainer`,
слушающий только `127.0.0.1:4196`. Он не выполняет workflow n8n.

Служба использует уже установленный неизменяемый образ с Node 24, readonly root,
пользователя 1000, снятые capabilities, ограничение памяти/CPU и автоперезапуск.
Исходники каждого выпуска лежат в отдельной директории с проверенными SHA-256.

## Доступ и расходы

- Supabase Auth проверяет текущую серверную запись пользователя. Допускаются
  только активные owner/admin/manager нужных продукта и организации.
- Точные Origin, обязательный Bearer, ограничение HTTP-тела/контекста/истории,
  фиксированные инструкции и модель. Клиент не выбирает модель или провайдера.
- OpenAI GPT-4.1 mini через OpenRouter; разрешён только провайдер OpenAI, fallback
  выключен. `max_price` привязан к проверенной цене; платные tools/search отсутствуют.
- Для Workspace действует **общий предел $5**. Он не обновляется автоматически.
  Суточные лимиты токенов — отдельный дополнительный предел.
- В SQLite атомарно резервируется верхняя оценка в целых нанодолларах; после
  ответа списывается `usage.cost`. Неопределённый сбой сохраняет полный резерв.
  Повторный requestId не тратит деньги повторно. Смена даты и рестарт не обнуляют бюджет.
- Дополнительно проверяется конечный лимит существующего серверного ключа
  провайдера. Его общий предел $10 не повышался; это НЕ бюджет Workspace.
  Другие интеграции не изменялись. Новый бюджет Workspace независимо ограничен $5.
- Сервер не журналирует транскрипты, ответы, токены авторизации или ключи. В SQLite
  только HMAC пользователя, requestId, дата, токены и расход/резерв. Разбор, который
  пользователь сохраняет в карточке, остаётся данными самого Workspace.

`health.ready=true` подтверждает доступ, конфигурацию и проверку лимита/цены.
`answerVerified=false` напоминает, что health не выполняет платную генерацию.
Реальная проверка четырёх режимов фиксируется отдельным live receipt.

## Приватная конфигурация

На AI-хосте: `/etc/vertux-workspace-trainer/runtime.env`, root-only.
Никакие значения ключей не включаются в Git, команды, скриншоты или receipts.

| Переменная | Назначение |
|---|---|
| TRAINER_ENABLED | Только точное true включает обработку |
| TRAINER_PRODUCT_ID, TRAINER_ORGANIZATION_ID | Подтверждённая область доступа |
| TRAINER_USAGE_SALT | Постоянный приватный HMAC-секрет, не короче 32 символов |
| TRAINER_OPENROUTER_KEY | Существующий серверный ключ с конечным лимитом |
| TRAINER_MODEL | openai/gpt-4.1-mini |
| TRAINER_MAX_KEY_USD | Проверяемый верхний предел ключа, сейчас 10 |
| TRAINER_TOTAL_BUDGET_USD | Общий предел именно Workspace, сейчас 5 |
| TRAINER_SUPABASE_ANON_KEY | Публичный ключ проверки Auth, не service role |
| TRAINER_DAILY_TOKENS, TRAINER_USER_DAILY_TOKENS | Общий/пользовательский дневной предел |
| TRAINER_REQUESTS_PER_MINUTE | Частота на пользователя |
| TRAINER_BUDGET_DB | /state/budget.sqlite в постоянном приватном mount |
| TRAINER_PORT | 4196, привязка только к loopback |

На Nexus-хосте `operator.env` содержит только несекретные параметры области,
модели и публичный Auth key для операторского smoke. Провайдерского ключа там нет.

## Выпуск и проверка

- `scripts/trainer-container-release.py` создаёт контейнер на AI-хосте, проверяет
  hashes, сохраняет backup nginx и проверяет отказ без авторизации. Существующий
  контейнер скрипт не перезаписывает автоматически: обновление требует подготовки
  нового экземпляра с сохранением одного постоянного ledger.
- `scripts/trainer-gateway-update.py` меняет только уже зарегистрированный точный
  маршрут Nexus, сохраняет backup и проверяет сертификат upstream с глубиной 3.
- `scripts/trainer-live-smoke.mjs` выполняется оператором на Nexus-хосте. Без
  `--allow-paid` проверяет только health. С этим флагом делает четыре генерации
  на вымышленном тексте, проверяет owner/manager, чужой Origin и повтор requestId.
  Временные сессии закрываются с scope=local; письма/приглашения не отправляются.
- Перед публикацией клиента нужны реальные ответы всех режимов, проверка
  сохранения ledger после рестарта и сверка отсутствия секретов в артефактах.
- Проверка микрофона проводится отдельно в установленном Nexus с гарнитурой.
  Web Speech не означает запись обеих сторон телефонного разговора.

проверить nginx и перезагрузить конфигурацию. Не активировать архивный n8n workflow.
Резервные копии бюджета и окружение остаются приватными на сервере.
